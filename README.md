🏀 KICKS & HOOPS — Basketball Sneaker Store

Премиальный e-commerce лендинг для сникер-хиддеров и баскетболистов. Проект разработан на чистом стеке HTML5, CSS3 (БЭМ + Tailwind) и JavaScript (ES6+).

🛠 Ключевой функционал:

Каталог на 40 моделей: Полная база кроссовок с фильтрацией по брендам и поиском.

Интерактивные модальные окна: Детальные карточки товаров с экспертными рекомендациями под разные игровые амплуа.

Адаптивный дизайн: Идеальная верстка под ПК, планшеты и смартфоны.
